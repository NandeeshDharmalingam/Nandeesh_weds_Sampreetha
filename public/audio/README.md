# Wedding music goes in this folder

Add your audio files here. The invitation works without them (the music button simply stays hidden until a file is found).

| File name (exactly) | What it is for | Needed? |
| --- | --- | --- |
| `wedding-instrumental.mp3` | Main background music. Soft flute or veena works well. Loops quietly while guests read. | Recommended |
| `optional-devotional-instrumental.mp3` | Second track guests can choose in the music options. | Optional |
| `wedding-celebration.mp3` | Festive instrumental that fades in at the final blessing, only if the guest is already listening. | Optional |
| `temple-bell.mp3` | Your own bell recording. Without it, a soft built-in bell is used. Also set `templeBell.file` in `config.js`. | Optional |

Tips

- MP3, about 128 to 192 kbps, a few minutes long and under 5 MB each, so phones load them quickly.
- Choose music that loops smoothly and has a similar loudness across tracks.
- To use different file names, change the paths in `config.js` under `music.tracks`.

Use only music you own, music the family has permission to use, or properly licensed recordings. Do not add commercial film or album recordings without permission.
